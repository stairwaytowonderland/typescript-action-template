# Function: kebabToCamel()

> **kebabToCamel**(`str`): `string`

Converts a kebab-case string to camelCase.

## Parameters

### str

`string`

The kebab-case string to be converted.

## Returns

`string`

The converted camelCase string.

## Example

```ts
kebabToCamel('kebab-case-string') // 'kebabCaseString'
```
